# Online Lawyer Appointment Booking System

## 🚀 Features
- Admin, Lawyer, Client modules
- OTP Authentication
- Appointment Booking
- Payment Integration
- Real-time Chat

## 🛠 Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## 📦 Installation

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend/online_lawyer_manageemnt
npm install
npm start
